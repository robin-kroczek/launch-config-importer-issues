# Security Policy

## Reporting a vulnerability

Please do **not** report security issues in a public issue.

Report them privately through
[GitHub private vulnerability reporting](https://github.com/robin-kroczek/launch-config-importer-issues/security/advisories/new)
or by email to **kontakt@rkroczek.de**.

Please include the plugin version, the IDE version and a description of how the issue can be
reproduced. You will receive an answer as soon as possible.

## Supported versions

Security fixes are provided for the latest released version of the plugin.
